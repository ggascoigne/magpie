# Magpie application icon

The Magpie application icon is an adapted version of
“Eurasian Magpie 2023-10-16 01.jpg” by Alexis Lours:
https://commons.wikimedia.org/wiki/File:Eurasian_Magpie_2023-10-16_01.jpg

Changes: cropped to a square, rocks and other background elements removed, and
the background replaced with a smooth sky-blue field.
